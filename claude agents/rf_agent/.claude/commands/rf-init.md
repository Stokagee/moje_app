# /rf-init

Initialize and map Robot Framework project.

## Usage
```
/rf-init [project_path]
```

## Workflow
1. Explore repository (structure, tests, resources, BE code)
2. Find existing common wrappers (common_api.resource, common_db.resource)
3. Analyze test organization and tags
4. Create project map
5. Suggest scaffolding if missing

## Load skill
- rf-init (for detailed workflow and conventions)

## Rules
- Don't create files without approval
- Always explore BE code for endpoint context
- If something is unclear, ask
